Forma GNU/Linux造形美Structural Beauty

Forma GNU/Linuxは、「造形美」をコンセプトとしたDebianベースのLinuxディストリビューションです。単に使いやすいだけではなく、ユーザーの手で最大限自由に、最大限簡単に「管理・カスタマイズ」できる環境を目指して開発を進めています。 Forma GNU/Linux is a Debian-based Linux distribution built around the concept of "structural beauty." Beyond simply being easy to use, it aims to give users as much freedom as possible to manage and customize their own systems, while keeping those tasks as simple as possible.

FEATURES

残すものと、手放すものKeep what you need, leave what you don't

Debianはあらゆるハードウェアをサポートするために、たくさんのカーネルモジュールを同梱しています。Formaはそれをtar.xzとしてアーカイブし、必要になればいつでも復元できる仕組みを提供します。 Debian bundles a large number of kernel modules to support a wide range of hardware. Forma archives the ones you don't use as tar.xz, so you can restore them any time.

📦

必要なものを選び、不要なものは持たないKeep what you need, leave what you don't

使用しないドライバーをtar.xzでアーカイブし、システム容量を節約。必要になったらいつでも展開して元に戻せます。Archive unused drivers as tar.xz to save space, restore them whenever needed.

🌐

オフラインを考慮した設計Built for offline use

インターネット環境がなくても基本的なセットアップや利用ができるよう設計。おまけでテトリスも同梱。Basic install and everyday use work fine with no internet. Tetris is included, for some reason.

🧰

独自コマンド forma / forma-tuiThe forma / forma-tui commands

ドライバ・パッケージ・カーネルモジュール・システム設定を一元管理するformaコマンド。TUIのforma-tuiも開発予定。The forma command manages drivers, packages, kernel modules, and settings. forma-tui brings the same to a keyboard-driven TUI.

💿

複数のエディションMultiple editions

用途に応じて5つのエディションを用意。Five editions — pick the one that fits you.

INSTALLER

Forma Installer

Forma Installerと呼ばれる独自のTUIインストーラーを採用。キーボードだけで直感的に操作できることを目標に開発しています。A custom TUI installer called Forma Installer. Designed for intuitive keyboard-only operation.

🐍

Pythonで開発Built with Python

開発効率や保守性、機能追加のしやすさを重視しPythonを採用。Python was chosen for development efficiency and maintainability.

⌨️

キーボード操作に特化Keyboard-first design

ディスク選択やユーザー設定など、基本的なインストール作業を分かりやすく。Disk selection and user settings — clear and straightforward.

PROJECT GOALS

プロジェクトの目的What we're building toward

Forma GNU/Linuxの目的は、最初から全部入りのLinuxを作ることではありません。必要なものを自分で選び、不要なものは持たない。そして、Linuxの仕組みをほんの少しでも理解しながら、自分だけの環境を構築できることを大切にしています。初心者から上級者まで、それぞれの知識や用途に合わせて自由にカスタマイズできるディストリビューションを目指しています。 Forma GNU/Linux isn't trying to be all-in-one. Choose what you need, let go of what you don't, and build your own environment while understanding the basics of how Linux works — that's the shape of this distribution.
